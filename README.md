# Relief — free public washrooms in Toronto & the GTA

Live site: https://khayoon.github.io/relief/

This repository only hosts the compiled website (browse-only mode). Washroom data combines open data from the City of Toronto, Toronto Public Library, City of Mississauga, Town of Whitby and OpenStreetMap. The open dataset is at `data/washrooms.geojson` (ODbL; see attributions below).
